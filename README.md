# FSU Division of Student Affairs Website Redesign

## Project Overview
This project focused on evaluating and improving the user experience and visual design of the Florida State University Division of Student Affairs (DSA) homepage. The goal was to identify areas of the original homepage that could be improved and develop a redesigned concept with a more engaging, organized, and interactive layout.

The project involved researching the existing website, creating a visual mockup, and implementing selected design improvements within a Drupal sandbox environment.

## Project Objectives
- Evaluate the original DSA homepage and identify areas for improvement.
- Develop design concepts to improve the website's visual presentation and user experience.
- Create interactive elements that make website navigation more engaging.
- Implement selected design changes using HTML and CSS within Drupal.

## Research and Website Evaluation
The first phase involved reviewing the existing DSA homepage to identify design inconsistencies, areas that could be better organized, and opportunities to improve the overall user experience. This research helped guide the redesign and determine which elements would be most beneficial to update.

## Design and Prototyping
After completing the initial research, I created a redesigned website mockup using Canva. The mockup served as a visual representation of the proposed design and helped establish the layout, appearance, and interactive elements before implementation.

## Development and Implementation
Following the design phase, I moved into the Drupal sandbox environment to implement selected improvements to the existing website
Using HTML and CSS, I developed an interactive image-circle layout featuring:
- Circular images that expand when users hover over them.
- Text overlays that appear when hovering over each image.
- Clickable titles that link to specific sections of the website.
- Hover effects that create a more interactive browsing experience.

These features were designed to improve visual engagement while providing users with additional navigation options.

## Technologies and Tools
- **HTML:** Used to structure the interactive website elements.
- **CSS:** Used to style the image circles, create hover effects, and control the layout and visual presentation.
- **Drupal:** Used to access and modify the website within a sandbox development environment.
- **Canva:** Used to create the initial website redesign mockup.

## Key Features
- Interactive circular image elements.
- Expandable images with hover effects.
- Text overlays displayed on hover.
- Clickable titles linking to other areas of the DSA website.
- Improved visual organization and user interaction.

## What I Learned
Through this project, I gained experience evaluating an existing website, translating design concepts into functional website elements, and working within a content management system. I also strengthened my understanding of HTML and CSS, particularly when creating interactive layouts and hover effects. The project provided an opportunity to experience the process of taking a website redesign from initial research and prototyping to implementation.
